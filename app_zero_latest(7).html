写真分析

ここが写メから分析へ入る入口です。今の版では、写真を入れる場所と、分析結果が出る場所を先に固めています。

まだプロンプトはコピーしていません。
まだチャッピーの返答は反映していません。
1. 問題を作る
問題作成タブで範囲と問題タイプを決め、印刷または保存します。
2. プロンプトをコピー
この画面でプロンプトを作り、写メと一緒にチャッピーへ送ります。
3. チャット分析を受け取る
返ってきた文章は見出しつきのまま下の欄へ貼ります。
4. レポートへ反映
「返答をレポートへ反映」を押すと、問題番号・特徴・誤答例・自由分析が自動で入ります。
この版はゼロ追加課金前提です。写メ分析そのものはチャッピーのチャット側で行い、この画面は「問題作成・印刷・分析用メモづくり・レポート反映」に使います。

チャッピーへ渡すための下書き欄

返答は、できるだけ見出しを変えずにそのまま貼ると自動反映が安定します。対応している見出しは「落とした問題番号 / 答案の特徴 / 誤答例 / ミスの型 / 原因 / 自由分析 / 学習レポート / 入塾クロージング資料」です。
今の版では、ここに作ったプロンプトをコピーしてチャットへ送り、返答を貼ってからレポートへ流し込む前提です。
